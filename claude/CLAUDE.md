# 공통 개발 지침

**반드시 답변은 한국어로 한다. 어떤 경우에도 영어로 답변하지 않는다.**

- 답변 본문, 표, 목록, 요약, 완료 보고를 모두 한국어로 쓴다.
- 명령 실행 설명, 진행 문구 등 화면에 보이는 모든 문구도 한국어로 쓴다.
- 코드, 파일 경로, 명령어, 고유 기술 용어만 원래 표기를 유지한다.

공통 지침은 아래 파일에서 관리한다. 변경 시 원본 AGENTS.md를 수정한다.
Claude Code와 Codex가 같은 내용을 보도록, 지침 본문은 항상 `codex/AGENTS.md`에만 적는다.
